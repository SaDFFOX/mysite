Раздел IV. Доказательства

Разобраны игровые механики, которые влияют на сбор и оценку доказательств. Эти особенности можно использовать как в защите, так и против обвинения.

4.1. Маска скрывает личность

Маска скрывает ваш никнейм над головой постоянно, однако при убийстве действует ограничение. Маска скрывает только одно убийство каждые 12 часов.

Проблема: исполнитель может остаться неустановленным.

Формулировка для суда:

Личность исполнителя не установлена. Доказательства не идентифицируют обвиняемого. Неустранимые сомнения толкуются в пользу обвиняемого.

4.2. Оторванная страница с подписью «скрыто»

Если на игроке надета маска, то при вырывании страницы из книги в поле «Подписан» не будет отображаться его никнейм. Вместо этого будет написано «скрыто».

Проблема: документ не идентифицирует автора.

Формулировка для суда:

Автор документа не установлен. Страница могла быть создана любым лицом. Документ не может быть положен в основу обвинения.

4.3. Оторванная страница как договор или расписка

Проблема: страница не заверена. Нет подписи. Нет свидетелей. Нет привязки к конкретной книге.

Формулировка для суда:

Документ не подтверждает волеизъявление стороны. Юридическая сила отсутствует. Прошу исключить документ из доказательств.

4.4. Оторванные страницы и порядок вырывания

Страницы вырываются строго по порядку — сначала первая, затем вторая, третья и так далее. Пустые страницы не могут быть вырваны.

Особенность: если страница существует, значит, до неё были заполнены предыдущие. Это можно использовать для проверки правдоподобности.

Формулировка для суда:

Представленная страница не соответствует механике. Невозможно вырвать данную страницу без предыдущих заполненных. Доказательство вызывает сомнения.

4.5. Скриншоты и видеозаписи

Наивысшую юридическую силу имеют: скриншоты с нарушениями (при условии чёткого обозначения нарушения), видеозаписи, логи сервера, показания свидетелей, признание нарушителя.

Требование к скриншоту: нарушение должно быть чётко обозначено.

Формулировка для суда:

Скриншот не содержит чёткого обозначения нарушения. Доказательство не соответствует требованиям. Прошу исключить его из дела.

4.6. Показания свидетелей

Наименьшую доказательную силу имеют свидетельские показания и устные подтверждения нарушений. Суд не вправе выносить приговор, основываясь исключительно на данной доказательной базе.

Формулировка для суда:

Обвинение строится только на свидетельских показаниях. Другие доказательства отсутствуют. Дело подлежит закрытию.
